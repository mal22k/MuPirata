// Estado actual   : ACTIVO; 3 planes configurados.
// Limite del source: MAX_CUSTOM_BUYVIP = 3, por eso solo existen Index 0, 1 y 2.
//
// FUNCION REAL DEL SISTEMA
// Define los paquetes VIP que el jugador puede comprar desde el cliente. Este
// sistema compra VIP de cuenta (AccountLevel), no VIP por personaje. Al comprar,
// el servidor descuenta coins y guarda el nivel VIP/fecha de expiracion en el
// JoinServer con GJAccountLevelSaveSend.
//
// FLUJO DE COMPRA
// 1. El cliente envia el paquete 0xF0 con VipType 1, 2 o 3.
// 2. El GS rechaza la compra si VipType es menor o igual al AccountLevel actual.
// 3. El GS pide al CashShop el saldo actual del jugador.
// 4. Cuando llega el saldo, valida Coin1/Coin2/Coin3.
// 5. Descuenta monedas con GDSetCoinSend y guarda el VIP por Days dias.
// 6. Recarga el AccountLevel y muestra el mensaje 758 de Message.txt.
//
// DIFERENCIA ENTRE INDEX Y VIPTYPE
// Esta es la parte que mas suele confundir:
// - En este archivo el Index empieza en 0.
// - En el paquete del cliente VipType empieza en 1.
// - El source usa GetInfo(VipType - 1).
//
// Por eso:
// Index 0 = VipType 1 = AccountLevel 1 = VIP Bronze
// Index 1 = VipType 2 = AccountLevel 2 = VIP Silver
// Index 2 = VipType 3 = AccountLevel 3 = VIP Gold
//
// MONEDAS
// Coin1 = WCoinC
// Coin2 = WCoinP
// Coin3 = GoblinPoint
//
// CAMPOS EXP Y DROP
// En esta clase se cargan en memoria, pero no aplican directamente el bonus al
// comprar. El VIP real queda definido por AccountLevel; las tasas efectivas de
// experiencia, drop, mezcla, reset, helper, etc. se toman de las configuraciones
// globales que usan AccountLevel en el GameServer.
//
// MENSAJES RELACIONADOS EN C:\MuServer\Data\Message.txt
// 757 = saldo insuficiente.
// 758 = compra/registro VIP correcto.
// 759 = ya tiene este VIP o uno superior.
//
// REGLAS DE EDICION
// - Mantenga solo Index 0, 1 y 2 salvo que tambien se aumente MAX_CUSTOM_BUYVIP
//   y se adapte el cliente.
// - VipName maximo recomendado: 31 caracteres.
// - Days se convierte internamente a segundos: Days * 86400.
// - No use * en este archivo; el parser espera numeros reales en campos numericos.
// - El bloque termina con end.
// ============================================================================
