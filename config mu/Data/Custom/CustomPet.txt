// Archivo usado por: CCustomPet::Load("Custom\\CustomPet.txt")
// Estado actual   : ACTIVO; contiene mascotas custom configuradas.
//
// FUNCION REAL DEL SISTEMA
// Define bonificaciones para pets/muun custom equipados en el slot 8 del
// personaje. El servidor identifica el pet por ItemIndex global y aplica bonos
// de vida, mana, ataque, velocidad, experiencia, resistencias, reflect, etc.
//
// IMPORTANTE SOBRE SECCIONES
// Este archivo NO usa secciones numericas. El source lee lineas directas hasta
// encontrar "end". No agregues "0", "1", "2", etc.
//
// ITEMINDEX GLOBAL
// ItemIndex usa el valor global GET_ITEM(Group,Index):
// ItemIndex = (Group * 512) + Index.
// Ejemplo: item grupo 13 index 168 => 13*512+168 = 6824.
//
// DONDE SE APLICA
// - El pet debe estar equipado en Inventory[8], slot de pet/mount.
// - CalcCustomPetOption aplica bonos si el item existe y tiene durabilidad > 0.
// - Attack.cpp aplica DamageRate al daño del atacante si lleva el pet equipado.
// - DamageSprite usa logica MuunPet para bajar durabilidad por daño recibido.
// - ObjectManager permite reparar/recuperar pets con Recovery != 0 como inmortales.
//
// CAMPOS Y FUNCION
// Index               : ID interno de la linea. Solo referencia administrativa.
// ItemIndex           : item global del pet. Es la clave real del sistema.
// HP                  : vida adicional plana. Suma a AddLife.
// MP                  : mana adicional plano. Suma a AddMana.
// DamageRate          : porcentaje de aumento de daño final del atacante.
//                       40 = daño * 140 / 100.
// AttackSpeed         : velocidad adicional. Suma a PhysiSpeed y MagicSpeed.
// DoubleDamage        : chance adicional de doble daño.
// TripleDamage        : chance adicional de triple daño.
// Experience          : bonus de EXP normal y master.
// ResistDouble        : intencion: resistir doble daño.
//                       ADVERTENCIA: en el source actual se lee pero NO se usa
//                       correctamente; se suma IncDoubleDamageRate a resistencia.
// ResistIgnoreDefense : resistencia contra ignore defense.
// ResistIgnoreSD      : resistencia contra ignore shield/SD.
// ResistCritical      : resistencia contra daño critico.
// ResistExcellent     : resistencia contra daño excellent.
// AntiStuck           : resistencia contra stun/traba.
// Reflect             : porcentaje/valor adicional de reflect.
// Recovery            : si es distinto de 0, PetIsInmortal devuelve true.
//                       En reparacion/recuperacion fuerza durabilidad a 255.
//
// DURABILIDAD
// Aunque Recovery puede hacerlo recuperable/inmortal al reparar, durante combate
// el pet custom entra por MuunPet y puede perder durabilidad segun daño recibido,
// m_MuunDurabilityRate y PetDurabilityRate del personaje.
//
// BALANCE
// Cuidado con DamageRate, DoubleDamage y AttackSpeed: estos valores afectan PvM
// y PvP porque modifican atributos reales del personaje. Valores altos pueden
// romper el balance especialmente con buffs, alas y sets full.
//
// REGLAS IMPORTANTES
// - Si repites el mismo ItemIndex, el std::map conserva la primera insercion y
//   puede ignorar duplicados posteriores. Evita duplicar ItemIndex.
// - Valores negativos no tienen proteccion especial en el source; usa 0 para
//   desactivar un bono.
// - El limite teorico de referencia es MAX_CUSTOM_PET 512, pero el contenedor
//   real es std::map.
//
// EJEMPLOS COMENTADOS
