// ============================================================================
// SILENTDEVS - CUSTOM ONLINE LOTTERY
// ============================================================================
// Archivo usado por: CCustomOnlineLottery::Load("Custom\\CustomOnlineLottery.txt")
// Estado actual   : ACTIVO si CustomOnlineLotterySwitch=1 en GameServerInfo.
//
// FUNCION REAL DEL SISTEMA
// Programa sorteos automaticos entre jugadores conectados. Cuando llega la hora
// configurada, el GS elige un jugador aleatorio, entrega monedas y tambien
// ejecuta un drop especial con ITEM_BAG_LOTTERY en la posicion del ganador.
//
// CONFIGURACION EXTERNA RELACIONADA
// CustomOnlineLotterySwitch : activa/desactiva el sistema.
// CustomOnlineLotteryText1  : aviso antes del sorteo. Usa Name y minutos.
// CustomOnlineLotteryText2  : aviso de ganador. Usa nombre del ganador.
// CustomOnlineLotteryText3  : aviso cuando no hay ganador.
//
// FLUJO REAL
// 1. El GS carga horarios de seccion 0.
// 2. Carga datos del sorteo de seccion 1.
// 3. Carga recompensa de monedas de seccion 2.
// 4. MainProc revisa cada segundo el proximo horario.
// 5. Durante AlarmMin avisa cada minuto.
// 6. Al llegar a 0, elige ganador random por mapa.
// 7. Entrega coins y dropea ITEM_BAG_LOTTERY al ganador.
// 8. Reprograma el siguiente horario.
//
// REGLA GENERAL DE *
// En horarios, * equivale a -1 y significa "cualquier valor" para ese campo.
//
// LIMITES Y DETALLES TECNICOS
// - Maximo de loterias configurables: 24 indices, de 0 a 23.
// - El Index de seccion 0, 1 y 2 debe coincidir para formar el mismo sorteo.
// - Si un index tiene horarios pero no tiene seccion 1/2 bien configurada,
//   puede quedar con nombre/mapa/premio por defecto o no operar como esperas.
// - RuleInfo.EventTime se fija en 0 en el GS, por eso el sorteo se resuelve
//   inmediatamente al llegar al horario.
// - m_CustomOnlineLotteryNoOff existe y filtra offstore/offattack/offline, pero
//   en el GS revisado no se observa lectura desde archivo .dat. Si necesitas
//   excluir offline de forma garantizada, conviene corregir/cargar ese valor.
//
// COMANDOS MANUALES
// El GS tambien tiene opciones de menu para StartNow(map), usando mapas como
// 0, 2, 3 y 51 segun GameServer.cpp. Ese modo manual usa el premio del Index 0.
// ============================================================================

// ============================================================================
// SECCION 0 - HORARIOS DEL SORTEO
// ============================================================================
// Index     : ID del sorteo. Debe coincidir con seccion 1 y 2.
// Year      : año exacto. * = cualquier año.
// Month     : mes exacto. * = cualquier mes.
// Day       : dia del mes exacto. * = cualquier dia.
// DayOfWeek : dia de la semana. * = cualquier dia de semana.
// Hour      : hora exacta en formato 24h. * = cualquier hora.
// Minute    : minuto exacto.
// Second    : segundo exacto.
//
// EJEMPLOS:
// - Todos los dias a las 20:30:00:
//   // 0 * * * * 20 30 0
// - Cada hora en el minuto 36:
//   // 0 * * * * * 36 0
//
// COLUMNA:
// Index Year Month Day DayOfWeek Hour Minute Second
0
     0    *     *    *     *       *     36     0
end

// ============================================================================
// SECCION 1 - DATOS DEL SORTEO
// ============================================================================
// Index    : ID del sorteo. Debe coincidir con seccion 0 y 2.
// Name     : nombre mostrado en avisos. Debe ir entre comillas si tiene espacios.
// Map      : mapa donde se eligen participantes.
//            >= 0 = solo jugadores conectados en ese mapa.
//            -1 o * = cualquier mapa.
// AlarmMin : minutos antes del sorteo para mostrar avisos globales.
//            Ejemplo: 5 avisa faltando 5,4,3,2,1 minutos.
//
// NOTA:
// El ganador se elige entre jugadores conectados GP/OBJECT_USER. Si Map filtra
// un mapa sin jugadores, el sistema muestra mensaje de "No Winner".
//
// COLUMNA:
// Index Name Map AlarmMin
1
     0   "Sorteo Online"       0         5            
end

// ============================================================================
// SECCION 2 - PREMIO EN MONEDAS
// ============================================================================
// Index : ID del sorteo. Debe coincidir con seccion 0 y 1.
// Coin1 : cantidad de Coin1 entregada al ganador.
// Coin2 : cantidad de Coin2 entregada al ganador.
// Coin3 : cantidad de Coin3 entregada al ganador.
//
// REGLAS:
// - Solo llama GDSetCoinSend si al menos una moneda es mayor a 0.
// - El motivo enviado al DataServer es "Lottery".
// - Ademas de coins, siempre intenta dropear ITEM_BAG_LOTTERY al ganador.
//
// COLUMNA:
// Index Coin1 Coin2 Coin3
2
     0     10	 0	   0		
end
