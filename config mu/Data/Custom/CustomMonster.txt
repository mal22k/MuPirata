// Archivo usado por: CCustomMonster::Load("Custom\\CustomMonster.txt")
// Estado actual   : ACTIVO; contiene reglas cargadas por el GameServer.
//
// FUNCION REAL DEL SISTEMA
// Permite modificar monstruos ya existentes sin tocar Monster.txt directamente.
// El servidor busca la regla por MonsterClass y mapa cuando el monstruo nace.
// Si encuentra una regla, aplica porcentajes sobre sus stats originales.
//
// IMPORTANTE SOBRE SECCIONES
// Este archivo NO usa secciones numericas. El source lee lineas directas hasta
// encontrar "end". Por eso no agregues "0", "1", "2", etc. como en otros .txt.
//
// ORDEN DE BUSQUEDA
// El servidor revisa las lineas en orden y usa la primera que coincida:
// - MonsterClass igual al monstruo.
// - MapNumber igual al mapa, o MapNumber = * para cualquier mapa.
//
// REGLA DE PORCENTAJES
// - 100 = conserva el valor original.
// - 150 = aumenta 50%.
// - 200 = duplica.
// - 50  = reduce a la mitad.
// - *   = -1, conserva el valor original para ese campo.
//
// CAMPOS Y FUNCION
// MonsterClass   : ID/clase del monstruo segun Monster.txt.
// MapNumber      : mapa donde aplica. * = cualquier mapa.
// HP%            : multiplica Life, MaxLife y ScriptMaxLife.
// DamageMin%     : multiplica PhysiDamageMin.
// DamageMax%     : multiplica PhysiDamageMax.
// Defense%       : multiplica Defense fisica.
// AttackRate%    : multiplica AttackSuccessRate.
// DefenseRate%   : multiplica DefenseSuccessRate.
// Experience%    : multiplica experiencia normal y master.
// KillMessage    : ID de mensaje global al morir. * = no enviar.
// InfoMessage    : ID de mensaje privado al killer. * = no enviar.
// Reward1-4      : valores enviados al DataServer como recompensa custom.
//                  Deben ser todos distintos de * para activar la recompensa.
//                  Reward1-3 tambien son usados por GetCoin(Type,Boss).
// SummonMonster  : MonsterClass que se invoca al morir. 0 = no invocar.
// SummonCount    : cantidad a invocar. * o 0 termina usando 1 si SummonMonster>0.
//
// NOTA SOBRE DEFENSA MAGICA
// En EX603 este archivo no modifica una defensa magica separada. Solo Defense.
// En compilaciones 701+ el mismo Defense% tambien escala defensa elemental.
//
// EJEMPLOS COMENTADOS
// 1) Boss mas resistente en cualquier mapa:
//    // 275 * 250 180 180 200 150 150 100 * * 0 0 0 0 0 *
//
// 2) Mismo monstruo, pero solo si aparece en mapa 2:
//    // 275 2 300 200 200 250 170 170 120 * * 0 0 0 0 0 *
//
// 3) Monstruo que al morir invoca 3 adds clase 42:
//    // 275 * 100 100 100 100 100 100 100 * * 0 0 0 0 42 3
//
// 4) Monstruo con recompensa custom y mensaje privado:
//    // 275 * 100 100 100 100 100 100 100 * 200 100 50 0 0 0 *
//
