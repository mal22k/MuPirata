//   Crea NPC de tipo Bot Buffer. Al interactuar con ellos, validan los requisitos del jugador,
//   aplican los buffs configurados y luego cobran el costo indicado.
//
// REGLAS IMPORTANTES
//   - Las secciones deben conservar los numeros 1, 2, 3 y 4, y cada una debe cerrar con "end".
//   - BotIndex relaciona al mismo bot entre todas las secciones. Rango valido: 0 a 99.
//   - Nombre admite hasta 10 caracteres por la estructura interna del GameServer.
//   - Cada BotIndex admite como maximo 5 skills en la seccion 4.
//   - Las lineas de bots no habilitados en la seccion 1 quedan como plantillas sin aparecer.
//   - Despues de editar, use Reload si su GameServer recarga BotSystem; de lo contrario reinicie GS.
//   - No cambie el orden de las columnas ni elimine la palabra "end".
//==================================================================================================
