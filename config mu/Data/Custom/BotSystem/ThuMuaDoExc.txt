//=================================================================================================================
// THUMUADOEXC.TXT - BOT COMPRADOR DE ITEMS EXCELLENT / ANCIENT
//=================================================================================================================
// ESTADO DEL ARCHIVO: ACTIVO Y EN USO.
//
// Funcion real:
//   El jugador entrega items al bot mediante trade. Cada item que tenga al menos
//   una opcion Excellent (m_NewOption != 0) O una opcion Ancient
//   (m_SetOption != 0) cuenta como item valido para una tirada de recompensa.
//
// Flujo de uso dentro del juego:
//   1. Hacer trade con el bot.
//   2. Colocar solamente los items Excellent/Ancient que se desean vender.
//   3. Confirmar el trade.
//   4. Por cada item valido se realiza una tirada independiente de exito.
//   5. Si acierta, entrega WCoinC aleatorio + WCoinP fijo.
//   6. Los items entregados se consumen tanto al acertar como al fallar.
//
// ADVERTENCIA CRITICA SOBRE EL TRADE:
//   El GS confirma la transaccion y limpia TODO el trade al terminar.
//   Un item normal no cuenta para la recompensa, pero tambien puede consumirse si
//   fue colocado junto con los demas. No coloque Zen ni items que no quiera perder.
//
// El bot NO hace lo siguiente:
//   - No transfiere opciones entre items.
//   - No devuelve el item cuando falla.
//   - No cobra Zen, WCoinC ni WCoinP.
//   - No utiliza actualmente las reglas Allow de la seccion 3.
//
// Limites y reglas generales:
//   BotIndex valido: 0 a 29.
//   Name: maximo 10 caracteres visibles.
//   Rate recomendado: 0 a 100.
//   WCoinCMin debe ser menor o igual que WCoinCMax.
//
// Activar/desactivar:
//   La columna Enabled de la seccion 1 controla cada bot:
//      0 = desactivado
//      1 = activado
//   En una recarga, use una fila con Enabled=0 para desactivar el bot de forma
//   segura. El codigo de reinicializacion esta comentado y quitar filas puede
//   conservar datos anteriores en memoria hasta reiniciar completamente el GS.
//
// Mensajes externos requeridos en Data\\Message.txt:
//   1156 = mensaje mostrado cuando la tirada falla.
//   1157 = mensaje mostrado cuando la tirada acierta.
//   1602 = anuncio global de la recompensa.
//   Los tres IDs ya estan configurados en Message.txt. Si se copia este bot a
//   otro MuServer, tambien deben copiarse esas entradas para evitar el mensaje
//   "Could not find message 1156/1157/1602!".
//=================================================================================================================

//=================================================================================================================
// SECCION 1 - IDENTIDAD, ESTADO, PROBABILIDAD Y POSICION DEL NPC
//=================================================================================================================
// Formato:
// BotIndex  Class  Enabled  ColorName  Rate  Name  Map  X  Y  Dir
//
// BotIndex  : identificador interno del bot (0 a 29).
// Class     : clase y apariencia base del personaje:
//                0/1/2   = DW / SM / GM
//               16/17/18 = DK / BK / BM
//               32/33/34 = Elf / ME / HE
//               48/50    = MG / DM
//               64/66    = DL / LE
//               80/81/82 = SU / BS / DS
//               96/98    = RF / FM
// Enabled   : 0 = no crear el bot; 1 = crear el bot.
// ColorName : se asigna directamente como PKLevel del NPC (rango historico 0-7).
// Rate      : porcentaje de exito por cada item valido.
//             El codigo genera un numero entre 1 y 100 y acierta si numero <= Rate.
//               0   = 0% de exito
//               50  = 50% de exito
//               100 = 100% de exito
//             Valores mayores que 100 tambien siempre aciertan, pero no se
//             recomiendan porque el campo interno es BYTE.
// Name      : nombre visible, entre comillas; maximo 10 caracteres.
// Map/X/Y   : mapa y coordenadas donde aparece.
// Dir       : direccion visual del NPC (0 a 7).
//
// Configuracion actual:
//   Bot 0 activo, apariencia DW, nombre "Test 2", Lorencia (145,139), 100% exito.
//-----------------------------------------------------------------------------------------------------------------
1
// BotIndex  Class  Enabled  ColorName  Rate  Name         Map  X    Y    Dir
0            0      1        0          50   "ExchangNPC"  0    145  139  1
end

//=================================================================================================================
// SECCION 2 - EQUIPO VISUAL DEL BOT
//=================================================================================================================
// Formato:
// BotIndex  Slot  Type  Index  Level  Opt
//
// BotIndex : bot definido en la seccion 1.
// Slot     : parte visual que se equipa:
//              0 = arma       1 = escudo     2 = casco
//              3 = armor      4 = pants      5 = gloves
//              6 = boots      7 = wings      8 = pet
// Type     : grupo del item.
// Index    : indice del item dentro del grupo.
// Level    : nivel visual del item (+0 a +15, segun compatibilidad).
// Opt      : opcion adicional visual/interna (normalmente 0 a 7).
//
// Esta seccion solo cambia la apariencia del NPC. No define los items aceptados,
// no cambia el porcentaje y no modifica la recompensa.
//
// Particularidad del source:
//   Los items visuales se crean con Skill=0 y Luck=1 de forma fija; Opt se usa
//   como opcion adicional. Estas opciones pertenecen solo al equipo visual del bot.
//-----------------------------------------------------------------------------------------------------------------
2
// BotIndex  Slot  Type  Index  Level  Opt
0            2     7     1      0      7
0            3     8     1      0      7
0            4     9     1      0      7
0            5     10    1      0      7
0            6     11    1      0      7
0            7     12    2      0      7
end

//=================================================================================================================
// SECCION 3 - CAMPOS ALLOW (CARGADOS, PERO SIN USO OPERATIVO)
//=================================================================================================================
// Formato:
// BotIndex  AllowLevel  AllowOpt  AllowLuck  AllowSkill  AllowExc
//
// El lector guarda los cinco valores, pero Alchemy() no consulta ninguno de ellos.
// Por tanto, en el source actual cambiar 0/1 NO modifica los items aceptados ni la
// recompensa. Se mantienen por compatibilidad con el formato original.
//
// AllowLevel : actualmente sin uso.
// AllowOpt   : actualmente sin uso.
// AllowLuck  : actualmente sin uso.
// AllowSkill : actualmente sin uso.
// AllowExc   : actualmente sin uso. Aunque valga 0, el bot sigue contando items
//              Excellent porque la validacion esta escrita directamente en Alchemy().
//-----------------------------------------------------------------------------------------------------------------
3
// BotIndex  AllowLevel  AllowOpt  AllowLuck  AllowSkill  AllowExc
0            1           1         1          1           1
end

//=================================================================================================================
// SECCION 4 - ACCESO VIP Y RECOMPENSA
//=================================================================================================================
// Formato real:
// BotIndex  OnlyVip  WCoinCMin  WCoinCMax  WCoinP
//
// BotIndex  : bot definido en la seccion 1.
// OnlyVip   : 0 = cualquier cuenta.
//             1 = exige AccountLevel mayor que 0.
//             El source compara exactamente con 1; use solamente 0 o 1.
// WCoinCMin : recompensa minima de WCoinC por cada tirada acertada.
// WCoinCMax : recompensa maxima de WCoinC por cada tirada acertada.
//             El valor se elige de forma inclusiva entre Min y Max.
// WCoinP    : recompensa fija de WCoinP por cada tirada acertada.
//
// REGLA CRITICA DEL RANGO:
//   WCoinCMin debe ser <= WCoinCMax. Un rango invertido o invalido llega a la
//   operacion rand() % (Max-Min+1) y puede provocar division por cero o cierre del GS.
//
// No existe una columna Zen ni un costo. Estos valores siempre son recompensas.
//
// Configuracion actual:
//   Cualquier cuenta; entre 1 y 100 WCoinC; 0 WCoinP; recompensa por item acertado.
//-----------------------------------------------------------------------------------------------------------------
4
// BotIndex  OnlyVip  WCoinCMin  WCoinCMax  WCoinP
0            0        1          100        0
end
