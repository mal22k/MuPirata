// ============================================================================
// SILENTDEVS - CUSTOM NPC MOVE
// ============================================================================
// Archivo usado por: CCustomNpcMove::Load("Custom\\CustomNpcMove.txt")
// Estado actual   : ACTIVO; contiene NPC de teletransporte cargados.
//
// FUNCION REAL DEL SISTEMA
// Permite crear NPC que mueven al jugador a un mapa/coordenada especifica al
// hablar con ellos. Es parecido a CustomMove.txt, pero en vez de usar comando
// por chat, se activa por click/habla con un NPC exacto.
//
// IMPORTANTE SOBRE SECCIONES
// Este archivo NO usa secciones numericas. El GS lee lineas directas hasta
// encontrar "end". No agregues "0", "1", "2", etc.
//
// COMO IDENTIFICA AL NPC
// La regla debe coincidir exactamente con:
// - MonsterClass del NPC.
// - Mapa donde esta parado el NPC.
// - Coordenada X del NPC.
// - Coordenada Y del NPC.
//
// Si mueves el NPC en MonsterSetBase, tambien debes actualizar NpcMap/NpcX/NpcY.
//
// CAMPOS Y FUNCION
// Index        : ID interno unico de la regla.
// MonsterClass : clase del NPC segun Monster.txt / MonsterSetBase.
// NpcMap       : mapa donde esta colocado el NPC.
// NpcX         : coordenada X exacta del NPC.
// NpcY         : coordenada Y exacta del NPC.
// DestMap      : mapa destino al que sera enviado el jugador.
// DestX        : coordenada X destino.
// DestY        : coordenada Y destino.
// MinLvl       : nivel minimo requerido. * = sin minimo.
// MaxLvl       : nivel maximo permitido. * = sin maximo.
// MinReset     : reset minimo requerido. * = sin minimo.
// MaxReset     : reset maximo permitido. * = sin maximo.
// MinMReset    : master reset minimo requerido. * = sin minimo.
// MaxMReset    : master reset maximo permitido. * = sin maximo.
// AccountLevel : nivel minimo de cuenta/VIP requerido.
//                0 normal, 1/2/3 segun niveles VIP configurados.
// AllowPK      : 1 permite mover PK; 0 bloquea PK nivel 5 o mayor.
//
// ORDEN DENTRO DE NPCTALK
// Este sistema se revisa DESPUES de CustomNpcCommand. Si un mismo NPC esta en
// CustomNpcCommand.txt y aqui, primero se ejecutara el comando y este move no
// llegara a procesarse.
//
// VALIDACIONES INTERNAS
// - * equivale a -1.
// - Si el jugador tiene trade/baul/shop/interfaz abierta, no lo mueve.
// - Si esta teletransportandose, muerto/regenerando o con Personal Shop, no mueve.
// - Atlans bloquea Uniria/Dinorant por logica oficial.
// - Icarus/Kanturu3 exigen alas, Dinorant o Fenrir por logica oficial.
// - Mapas Gens Battle exigen familia Gens si aplica.
//
// DETALLE TECNICO IMPORTANTE
// En el GS actual, la validacion de MinMReset depende de MinReset != *
// y la de MaxMReset depende de MaxReset != *. Para exigir MasterReset de forma
// confiable, coloca tambien MinReset/MaxReset coherentes.
//
// EJEMPLOS COMENTADOS
// 1) NPC clase 602 en Lorencia que mueve a mapa 40:
//    // 0 602 0 126 143 40 237 235 10 * * * * * 0 1
//
// 2) NPC VIP Gold o superior que mueve a arena:
//    // 2 604 0 130 143 6 20 66 1 * * * * * 2 1
//
// 3) NPC que no permite PK rojo:
//    // 3 605 0 132 143 2 222 73 50 * * * * * 0 0
//
// COLUMNA OFICIAL
// Index MonsterClass   NpcMap   NpcX   NpcY   DestMap   DestX   DestY   MinLvl   MaxLvl   MinReset   MaxReset   MinMReset   MaxMReset    AccountLevel   AllowPK
// ============================================================================

     0      602           0	     126    143	      40	  237	  235	   10		*		*		      *		     *		      *		         0		    1	//Move To Silent Teste
     1      603           0	     128    143	      30	  87	  213	   50		*		*		      *		     *		      *		         0		    1	//Move To Devias Teste
end
