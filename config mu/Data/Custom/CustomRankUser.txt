// FUNCION:
// Define el titulo/rango visible del personaje usando una tabla de progreso.
// El GS calcula el rango con CCustomRankUser::GetRankIndex() y lo envia al
// cliente por paquete F3:E5 para mostrarlo encima del personaje.
//
// CONFIGURACION RECOMENDADA PARA ESTE ARCHIVO:
// - Usar CustomRankUserType=0 en la configuracion del GS.
// - Con CustomRankUserType=0 el sistema toma SOLO el Reset del personaje.
//
// MODOS SOPORTADOS POR EL SOURCE:
// - CustomRankUserType=0 o distinto de 1/2: usa Reset.
// - CustomRankUserType=1: usa MasterReset.
// - CustomRankUserType=2: usa Level + MasterLevel.
//
// NOTA IMPORTANTE:
// Para el esquema actual NO se recomienda usar Level + MasterLevel, porque un
// personaje puede desbloquear titulos solo por subir nivel/master. Este archivo
// queda organizado por resets para que sea facil de administrar.
//
// EJEMPLO DEL ESQUEMA ACTUAL:
// - Reset 0   a 100  = Novato
// - Reset 101 a 200  = Aprendiz
// - Reset 201 a 300  = Mensageiro
// - Reset 301 a 400  = Cazador
//
// RECOMPENSAS:
// Coin1/Coin2/Coin3 son recompensas opcionales por alcanzar exactamente el
// MinValue del rango. Solo se entregan si CustomRankUserRewardSwitch=1.
//
// DIFERENCIA CON CustomRanking.txt:
// - CustomRankUser.txt = titulo/rango propio del jugador.
// - CustomRanking.txt  = ventana/listado de ranking del juego.
//
// REGLAS:
// - MinValue y MaxValue definen el intervalo del rango.
// - MaxValue=-1 significa sin limite superior.
// - Evita rangos superpuestos; si dos rangos coinciden, gana el primero que
//   encuentre el source.
// - Los indices deben mantenerse ordenados.
// ============================================================================
