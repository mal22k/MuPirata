// FUNCION REAL DEL SISTEMA
// Define las arenas PvP programadas que aparecen en el panel del GameServer y
// en el panel de eventos del cliente. Cada arena usa un indice interno del 0 al
// 29, un horario de apertura, una regla de entrada y un gate de ingreso.
//
// FLUJO DEL EVENTO
// 1. EMPTY  : espera el proximo horario declarado en la seccion 0.
// 2. ALARMA : cuando faltan AlarmMin minutos, abre la entrada por StartGate.
// 3. STAND  : al cerrar la entrada, espera StandMin minutos antes de iniciar.
// 4. START  : pelea activa durante EventMin minutos.
// 5. CLEAN  : calcula ranking, guarda resultado y expulsa por FinalGate.
//
// PUNTUACION
// Al matar: el atacante gana CustomArenaKillerScoreIncrease puntos.
// Al morir: la victima pierde CustomArenaVictimScoreDecrease puntos, sin bajar
// de 0. En tu configuracion actual: +100 por kill y -10 por muerte.
//
// RESTRICCIONES IMPORTANTES
// - El jugador no puede entrar si esta en party, guerra de guild, duelo o tienda.
// - Al entrar, el servidor limpia todos los buffs/efectos activos del personaje.
// - Solo pueden atacar dentro de la arena durante el estado START.
// - Si MaxDeath no es *, al alcanzar ese numero de muertes el jugador sale por
//   FinalGate y se guarda su ranking con posicion 0.
// - RequireClass valida clase y evolucion: 0 = no entra, 1 = clase base o mayor,
//   2 = segunda evolucion o mayor, 3 = tercera evolucion.
//
// MAPA Y GATES
// Custom Arena usa MAP_SILENT, que en este emulador es el mapa 40.
// Los StartGate actuales 450-457 estan definidos en Data\Move\Gate.txt y deben
// llevar a zonas de arena compatibles. Si se cambia un StartGate, tambien debe
// existir en Gate.txt y conviene actualizar Custom\MonsterEvent\CustomEventTime.xml
// para que el panel H siga mostrando el boton/movimiento correcto.
//
// SIGNIFICADO DE *
// En este archivo, * se interpreta como -1. En campos de tiempo significa
// "cualquier valor"; en limites significa "sin limite".
//
// No elimine columnas ni cambie el orden de secciones. Los bloques terminan con
// end y el parser depende de ese formato.
// ============================================================================

// ============================================================================
// SECCION 0 - HORARIOS DE APERTURA
// ============================================================================
// Cada linea programa un intento de apertura para una arena.
//
// Index     : indice de arena definido en la seccion 1.
// Year      : anio exacto o * para todos.
// Month     : mes exacto o * para todos.
// Day       : dia del mes o * para todos.
// DayOfWeek : dia de semana o * para todos. En esta base, 7 se usa como domingo.
// Hour      : hora 0-23 o * para todas las horas.
// Minute    : minuto 0-59.
// Second    : segundo 0-59.
//
// Ejemplo actual:
// Arena 0 (SURVIVOR) abre cada hora al minuto 10.
// Arenas 1-7 abren los domingos entre 17:00 y 19:00, cada 20 minutos.
//
// Index  Year  Month  Day  DayOfWeek  Hour  Minute  Second
0
0         *      *       *     *       *     10        0
1         *      *       *     7       17    00        0
2         *      *       *     7       17    20        0
3         *      *       *     7       17    40        0
4         *      *       *     7       18    00        0
5         *      *       *     7       18    20        0
6         *      *       *     7       18    40        0
7         *      *       *     7       19    00        0
end
