// ============================================================================
// SILENTDEVS - CUSTOM QUEST
// ============================================================================
// Archivo usado por: CCustomQuest::Load("Custom\\CustomQuest.txt")
// Estado actual   : ACTIVO si CustomQuestSwitch=1 en GameServerInfo.
//
// FUNCION REAL DEL SISTEMA
// Define una cadena de quests globales/progresivas por personaje. El progreso
// se guarda como lpObj->CustomQuest y la proxima quest activa siempre es:
// quest actual = lpObj->CustomQuest + 1.
//
// DIFERENCIA CON CustomNpcQuest.txt
// CustomQuest.txt:
// - Es una cadena lineal/global.
// - El personaje avanza Quest 1, luego Quest 2, luego Quest 3...
// - Se abre con el NPC configurado en CustomNpcTalkQuest o por comando.
// - No define NPC por cada quest dentro del archivo.
//
// CustomNpcQuest.txt:
// - Define NPC exacto por quest: MonsterClass + Map + X + Y.
// - Puede manejar quests independientes por NPC.
// - Tiene limite MaxQuest/OpenNpc por NPC.
// - Reutiliza las mismas estructuras base de requisitos/recompensas, pero el
//   flujo y el guardado son distintos.
//
// COMO SE ACTIVA
// - Al entrar el personaje, el GS consulta al DataServer su progreso CustomQuest.
// - Si habla con el NPC cuya clase coincide con CustomNpcTalkQuest, se abre la
//   ventana/info de quest mediante QuestNpcTalk().
// - Tambien puede completarse por el comando asociado a COMMAND_CUSTOMQUEST si
//   esta disponible en CommandManager.
// - El cliente puede enviar el paquete de completar quest y el GS ejecuta la
//   misma validacion interna.
//
// FLUJO REAL
// 1. Determina quest activa = CustomQuest + 1.
// 2. Muestra titulo, descripcion y requisitos de seccion 7/0/1/2.
// 3. Valida requisitos de personaje, items y monstruos.
// 4. Valida espacio para recompensas de item.
// 5. Incrementa lpObj->CustomQuest.
// 6. Guarda el nuevo progreso en DataServer.
// 7. Consume items/costos.
// 8. Entrega monedas, items, buffs y experiencia.
//
// REGLA GENERAL DE *
// En este archivo * se lee como -1. En requisitos significa "no exigir" para
// ese campo. En Class de recompensa significa "cualquier clase".
//
// LIMITES
// - MAX_CUSTOM_QUEST existe como referencia de 50.
// - La ventana solo muestra hasta MAX_CUSTOM_QUEST_VIEW_REQ = 12 requisitos.
//   Si agregas demasiados requisitos a una quest, visualmente pueden no verse
//   todos aunque el servidor los siga validando.
//
// SECCIONES DEL ARCHIVO
// 0 = requisitos del personaje y costos.
// 1 = items requeridos y consumidos.
// 2 = monstruos requeridos.
// 3 = recompensa de monedas.
// 4 = recompensa de items.
// 5 = recompensa de efecto/buff temporal.
// 6 = recompensa de experiencia.
// 7 = titulo y descripcion visual de la quest.
// ============================================================================

// ============================================================================
// SECCION 0 - REQUISITOS DEL PERSONAJE Y COSTOS
// ============================================================================
// Quest       : numero de quest dentro de la cadena progresiva.
// Level       : nivel minimo requerido. * o 0 = no exigir.
// Reset       : resets minimos requeridos. * o 0 = no exigir.
// MasterReset : master resets minimos requeridos. * o 0 = no exigir.
// Zen         : zen requerido y consumido al completar. * o 0 = no cobrar.
// Coin1       : Coin1 requerido y consumido al completar. * o 0 = no cobrar.
// Coin2       : Coin2 requerido y consumido al completar. * o 0 = no cobrar.
// Coin3       : Coin3 requerido y consumido al completar. * o 0 = no cobrar.
// VipLevel    : AccountLevel minimo requerido. * = no exigir.
// RankUser    : rango custom minimo requerido segun gCustomRankUser. * = no exigir.
// Kills       : kills minimas requeridas. * o 0 = no exigir.
//
// COLUMNA:
// Quest Level  Reset   MasterReset   Zen   Coin1   Coin2   Coin3   VipLevel   RankUser   Kills
0
	1	  20	1000	    3	      1000	  0	      0	      0	       *	     *	       *
	2	  200	1000	    5	      1000	  0	      0	      0	       *	     *	       *
	3	  400	1000	    10	      1000	  0	      0	      0	       *	     *	       *

end

// ============================================================================

// ============================================================================
// Quest     : numero de quest.
// ItemGroup : grupo/categoria del item.
// ItemIndex : index dentro del grupo.
// Level     : nivel exacto requerido. * = cualquier nivel.
// Luck      : luck exacto requerido. 1 = con luck, 0 = sin luck, * = cualquiera.
// Skill     : skill exacto requerido. 1 = con skill, 0 = sin skill, * = cualquiera.
// Quantity  : cantidad requerida. Se elimina al completar la quest.
//
// COMO BUSCA ITEMS
// Revisa inventario principal desde slot 12 hasta Inventario Expandido
// No cuenta items equipados.
//

	3	       14	       42	     *	     *	    *	      15

end

// ============================================================================
// SECCION 2 - MONSTRUOS REQUERIDOS
// ============================================================================
// Quest        : numero de quest.
// MonsterClass : clase del monstruo que debe matar. * = sin monstruo requerido.
// Quantity     : cantidad requerida. * o 0 = sin cantidad valida.
//
// COMO FUNCIONA EL PROGRESO
// Cuando la quest activa tiene un MonsterClass valido, el GS guarda:
// CustomQuestMonsterIndex = MonsterClass.
// CustomQuestMonsterQtd   = cantidad restante.
// Cada kill contra ese MonsterClass reduce la cantidad restante.
//
// LIMITACION
// El GS maneja un MonsterClass activo en memoria por personaje. Si colocas
// varias lineas de monstruo para la misma quest, prueba con cuidado.
//
// COLUMNA:
//   Quest   MonsterClass   Quantity
2
	   1	       *	       *
	   2	       *	       *
	   3	       20	       50
end

// ============================================================================
// SECCION 4 - RECOMPENSA DE ITEM
// ============================================================================
// Quest      : numero de quest.
// ItemGroup  : grupo/categoria del item recompensa.
// ItemIndex  : index dentro del grupo.
// Level      : nivel del item creado.
// Durability : se lee, pero el source crea el item con durabilidad 0; el sistema
//              calcula la durabilidad base.
// Skill      : 1 = con skill, 0 = sin skill.
// Luck       : 1 = con luck, 0 = sin luck.
// Option     : option/adicional del item.
// Excellent  : mascara excellent. 0 = ninguna, 63 = todas.
// Ancient    : opcion ancient/set. 0 = ninguna.
// JOH        : opcion Jewel of Harmony.
// Option380  : opcion 380.
// Socket1-5  : sockets. 255 = vacio/no usado.
// Duration   : segundos de duracion del item. 0 = permanente.
// Class      : clase que puede recibir esta recompensa.
//0 = DW / SM
//1 = DK / BK
//2 = ELF / ME
//3 = MG
//4 = DL
//5 = SUM
//6 = RF
//* = cualquier clase
//
// VALIDACION DE ESPACIO
// Antes de completar, el GS verifica espacio para cada item recompensa aplicable
// a la clase del personaje.
//
// COLUMNA:
// Quest   ItemGroup   ItemIndex   Level   Durability   Skill   Luck   Option   Excellent   Ancient   JOH   Option380   Socket1   Socket2   Socket3   Socket4   Socket5   Duration   Class
4
	 1 	       14          13        0          0         0       0      0          0	        0   	0	     0	       255   	 255	  255	    255	      255	      0	       *
	 2 	       7           1         9          0         0       1      28         63	        5   	0	     0	       255   	 255	  255	    255	      255	      3600     *
	 3 	       0           22        15         255       1       1      28         63	        0   	1	     1	       255   	 255	  255	    255	      255	      7200     *
end
