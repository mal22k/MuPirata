// ============================================================================
// SILENTDEVS - CUSTOM NPC COMMAND
// ============================================================================
// Archivo usado por: CCustomNpcCommand::Load("Custom\\CustomNpcCommand.txt")
// Estado actual   : ACTIVO; contiene NPC que ejecutan comandos al hablar.
//
// FUNCION REAL DEL SISTEMA
// Permite que un NPC ejecute un comando existente del servidor cuando el jugador
// le hace click/habla con el. Ejemplo: NPC reset, NPC limpiar PK, etc.
//
// IMPORTANTE SOBRE SECCIONES
// Este archivo NO usa secciones numericas. El GS lee lineas directas hasta
// encontrar "end". No agregues "0", "1", "2", etc.
//
// COMO IDENTIFICA AL NPC
// La regla debe coincidir exactamente con:
// - MonsterClass del NPC.
// - Mapa.
// - Coordenada X.
// - Coordenada Y.
//
// Si mueves el NPC en MonsterSetBase, tambien debes actualizar X/Y aqui.
//
// CAMPOS Y FUNCION
// Index        : ID interno unico de la regla.
// MonsterClass : clase del NPC segun Monster.txt / MonsterSetBase.
// Map          : mapa donde esta colocado el NPC.
// X            : coordenada X exacta del NPC.
// Y            : coordenada Y exacta del NPC.
// TalkMode     : modo de ejecucion:
//                1 = ejecuta el comando pasando el indice del NPC.
//                0 = ejecuta el comando sin indice de NPC (-1).
// Command      : comando exacto entre comillas. Debe existir en CommandManager.
//
// ORDEN DENTRO DE NPCTALK
// Este sistema se revisa antes de CustomNpcMove y antes de varios dialogos
// normales. Si colocas aqui un NPC que tambien tiene otra funcion, este comando
// puede interceptar el click y evitar que se abra la funcion original.
//
// REGLAS IMPORTANTES
// - El comando debe incluir "/" si el comando normal lo usa.
// - Si el comando necesita parametros, deben ir dentro de las comillas.
// - Command acepta hasta 127 caracteres por el buffer del GS.
// - Este sistema depende de GAMESERVER_CLIENTE_UPDATE >= 15 en el GS actual.
//
// EJEMPLOS COMENTADOS
// 1) NPC de reset:
//    // 0 501 0 126 143 1 "/reset "
//
// 2) NPC para limpiar PK:
//    // 1 502 0 128 143 1 "/pk"
//
// 3) NPC que ejecuta un comando VIP sin pasar indice de NPC:
//    // 2 503 0 130 143 0 "/vip"
//
// COLUMNA OFICIAL
// Index MonsterClass Map   X     Y     TalkMode   Command
// ============================================================================

     0       501	   0   126	 143	    1	    "/reset "	//NPC RESET
     1       502	   0   128	 143	    1	    "/pk"		//NPC PKCLEAR
end
