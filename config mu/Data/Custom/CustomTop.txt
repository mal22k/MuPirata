// ESTADO VALIDADO:
// - ACTIVO.
// - Cargado por GS desde: Custom\CustomTop.txt
// - Source GS: CCustomTop::Load()
// - Comando relacionado: /top
// - DataServer consulta el procedimiento SQL: WZ_CustomTop
//
// FUNCION REAL:
// Este archivo define los tipos de ranking que el comando /top puede pedir.
// No calcula el ranking directamente. Solo registra:
// - que palabra usara el jugador en el comando;
// - que ID numerico se enviara al DataServer;
// - que titulo se mostrara antes de listar el resultado.
//
// FLUJO:
// 1. El jugador escribe:
//    /top rr
//    /top mr
//    /top rr dk
//
// 2. El GS busca el texto escrito en la columna Name.
//
// 3. Si lo encuentra, envia al DataServer:
//    - Index  = tipo de ranking.
//    - Clase  = filtro opcional por clase.
//
// 4. El DataServer ejecuta:
//    EXEC WZ_CustomTop Index, Clase
//
// 5. El GS muestra el titulo configurado en Title y lista los resultados.
//
// CLASES SOPORTADAS POR EL COMANDO:
// - Sin clase: muestra ranking general.
// - dw : Dark Wizard / Soul Master / Grand Master
// - dk : Dark Knight / Blade Knight / Blade Master
// - fe : Fairy Elf / Muse Elf / High Elf
// - mg : Magic Gladiator / Duel Master
// - dl : Dark Lord / Lord Emperor
// - su : Summoner / Bloody Summoner / Dimension Master
// - rf : Rage Fighter / Fist Master
//
// EJEMPLOS DE USO EN JUEGO:
// - /top rr       -> muestra TOP RR general.
// - /top mr       -> muestra TOP MR general.
// - /top rr dk    -> muestra TOP RR filtrado por DK.
// - /top mr rf    -> muestra TOP MR filtrado por RF.
//
// IMPORTANTE:
// - Si agregas un nuevo tipo aqui, tambien debe existir soporte para ese Index
//   dentro del procedimiento SQL WZ_CustomTop.
// - Si el SQL no reconoce el Index, el comando puede no mostrar resultados.
// - Name debe ser corto: el source usa char Name[10].
// - Title debe ser moderado: el source usa char Title[32].
// - Este archivo NO usa secciones numericas ni requiere "end".
// - El parser termina al llegar al fin del archivo o si encuentra "end".
//
// COLUMNAS:
// Index : ID numerico enviado al DataServer/SQL.
// Name  : palabra que el jugador escribe despues de /top.
// Title : titulo visible antes de imprimir los resultados.
//
// FORMATO:
// Index   Name   Title
// ============================================================================
