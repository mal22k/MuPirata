//==================================================
// SECCION 10 - BALANCE PVP DEL BOTBOSS
//==================================================
// Enable DefenseBypass DamageReductionBypass SocketReductionBypass WingAbsorbBypass FinalDamage MinDamageHP MinDamageFlat
//
// Esta seccion SOLO afecta cuando el BotBoss golpea a jugadores.
// No modifica PvP normal, PvM normal, bosses comunes ni otros monsters.
//
// Enable:
//   0 = desactivado.
//   1 = activado.
//
// DefenseBypass:
//   Porcentaje de defensa del jugador que el BotBoss ignora antes de calcular dano.
//   Ejemplo: 35 = ignora 35% de defensa.
//
// DamageReductionBypass:
//   Recupera parte del dano perdido por reducciones generales:
//   set, excellent, socket, buffs defensivos y opciones similares.
//
// SocketReductionBypass:
//   Penetracion extra SOLO contra la reduccion generada por socket options.
//   Es adicional a DamageReductionBypass y esta pensada para sets con 5 sockets lvl 5.
//
// WingAbsorbBypass:
//   Recupera parte del dano absorbido por wings/capas.
//   Esta es la clave contra alas +15 muy defensivas.
//
// FinalDamage:
//   Multiplicador final del dano del BotBoss contra jugadores.
//   100 = normal, 120 = +20%, 150 = +50%.
//
// MinDamageHP:
//   Dano minimo garantizado como porcentaje del HP maximo del jugador.
//   0 = sin minimo por HP.
//   Recomendacion inicial: 0 o 1. Usar alto puede volverlo injusto.
//
// MinDamageFlat:
//   Dano minimo plano garantizado.
//   0 = sin minimo plano.
//
// Recomendacion inicial para evento dificil pero no absurdo:
//   1 35 25 45 45 115 0 0
// Si con wings aun pega poco:
//   sube WingAbsorbBypass a 60 o FinalDamage a 125.
// Si con socket lvl 5 aun pega poco:
//   sube SocketReductionBypass a 60 o 70.
// Si pega demasiado:
//   baja FinalDamage a 100, SocketReductionBypass a 30 o WingAbsorbBypass a 30.
//==================================================
10
// Enable   DefBypass   DmgRedBypass   SocketBypass   WingBypass   Final   MinHP   MinFlat
     1          35           25             45            45        115      0        0
end
