// FUNCION REAL DEL SISTEMA
// Permite crear comandos personalizados de teletransporte, por ejemplo /pvp1,
// /arena1, /bar, /irbau, etc. El jugador escribe el comando y el GameServer
// valida requisitos antes de moverlo al mapa/coordenada indicada.
//
// IMPORTANTE SOBRE SECCIONES
// Este archivo NO usa secciones numericas. El source lee lineas directas hasta
// encontrar "end". No agregues "0", "1", "2", etc.
//
// CAMPOS Y FUNCION
// Index           : ID interno del destino. Debe ser unico.
// Command         : comando exacto entre comillas. Ejemplo: "/pvp1".
// Map             : numero de mapa destino.
// X               : coordenada X destino.
// Y               : coordenada Y destino.
// MinLevel        : nivel minimo requerido. * = sin minimo.
// MaxLevel        : nivel maximo permitido. * = sin maximo.
// MinReset        : reset minimo requerido. * = sin minimo.
// MaxReset        : reset maximo permitido. * = sin maximo.
// MinMasterReset  : master reset minimo requerido. * = sin minimo.
// MaxMasterReset  : master reset maximo permitido. * = sin maximo.
// AccountLevel    : nivel minimo de cuenta/VIP requerido.
//                   0 normal, 1/2/3 segun niveles VIP configurados en el server.
// AllowPK         : 1 permite mover PK; 0 bloquea PK nivel 5 o mayor.
//
// REGLAS Y VALIDACIONES INTERNAS
// - * equivale a -1.
// - Si el jugador tiene trade/baul/shop/interfaz abierta, no lo mueve.
// - Si esta teletransportandose, muerto/regenerando o con Personal Shop, no mueve.
// - Atlans bloquea Uniria/Dinorant por logica oficial.
// - Icarus/Kanturu3 exigen alas, Dinorant o Fenrir por logica oficial.
// - Mapas Gens Battle exigen familia Gens si aplica.
//
// DETALLE TECNICO IMPORTANTE
// En el source actual, la validacion de MinMasterReset depende de MinReset != *
// y la de MaxMasterReset depende de MaxReset != *. Para evitar sorpresas, si
// quieres exigir MasterReset, coloca tambien MinReset/MaxReset coherentes.
//
// EJEMPLOS COMENTADOS
// 1) Mover a Lorencia bar desde nivel 1, cualquier cuenta, permite PK:
//    // 100 "/bar2" 0 124 132 1 * * * * * 0 1
//
// 2) Zona VIP Gold o superior:
//    // 101 "/vipzone" 6 20 66 1 * * * * * 2 1
//
// 3) Zona PvP que no permite PK rojo:
//    // 102 "/pvpclean" 2 222 73 50 * * * * * 0 0
