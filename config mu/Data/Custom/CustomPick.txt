// Archivo usado por: CCustomPick::Load("Custom\\CustomPick.txt")
// Estado actual   : ACTIVO; usado por el comando /pick y gObjPickProc().
//
// FUNCION REAL DEL SISTEMA
// Define palabras/filtros que el jugador puede usar con /pick para activar o
// desactivar la recoleccion automatica de items especificos.
//
// EJEMPLO DE USO EN JUEGO
// /pick bless     -> activa/desactiva recoleccion de Jewel of Bless.
// /pick soul      -> activa/desactiva recoleccion de Jewel of Soul.
// /pick exc       -> activa/desactiva recoleccion de items excellent.
// /pick socket    -> activa/desactiva recoleccion de items socket.
// /pick setitem   -> activa/desactiva recoleccion de items ancient/set.
//
// IMPORTANTE SOBRE SECCIONES
// Este archivo NO usa secciones numericas. El source lee lineas directas hasta
// encontrar "end". No agregues "0", "1", "2", etc.
//
// CAMPOS Y FUNCION
// Index      : posicion interna del filtro dentro de lpObj->Pickup[Index].
//              Debe ser unico y estar entre 0 y 19, porque MAX_CUSTOMPICK=20.
// FilterName : palabra que se escribe despues de /pick. Debe ir entre comillas.
// ItemGroup  : grupo/categoria del item.
// ItemIndex  : index dentro del grupo.
//
// ITEMINDEX GLOBAL
// Internamente el item se guarda como:
// ItemGlobal = (ItemGroup * 512) + ItemIndex.
//
// COMO RECOGE ITEMS
// - gObjPickProc revisa periodicamente a los jugadores conectados.
// - Si PickupEnable=1, llama PickProc().
// - PickProc llama ItemGet().
// - ItemGet revisa items visibles dentro del rango de vista del mapa.
// - Si el item coincide con un filtro activo, intenta meterlo al inventario.
// - Si es zen, lo suma directo al dinero del personaje.
//
// REGLAS Y LIMITACIONES
// - No recoge items de evento: lpItem->IsEventItem() se ignora.
// - Si el inventario esta lleno, no puede recoger items normales.
// - Si el jugador abre interfaz, teleporta, muere/regenera o abre Personal Shop,
//   el sistema desactiva el pick y limpia los filtros.
// - Si el jugador esta en zona con atributo bloqueado, tambien se desactiva.
// - El filtro se compara solo por ItemIndex global, no por level, luck, skill,
//   excellent, socket, durabilidad ni opciones.
//
// FILTROS ESPECIALES QUE NO ESTAN EN ESTE ARCHIVO
// exc     : recoge cualquier item excellent.
// socket  : recoge cualquier item socket.
// setitem : recoge cualquier item ancient/set.
//
// ADVERTENCIA TECNICA
// El source usa lpObj->Pickup[CustomPickInfo.Index]. Si configuras Index mayor
// a 19, puede escribir fuera del arreglo. Mantener Index 0-19 es obligatorio.
//
// EJEMPLOS COMENTADOS
// 1) Agregar filtro para Jewel of Creation:
//    // 5 "creation" 14 22
//
// 2) Agregar filtro para Gemstone:
//    // 6 "gemstone" 14 41
//
// 3) Agregar filtro para Rena:
//    // 7 "rena" 14 21
//
// COLUMNA OFICIAL
// Index FilterName ItemGroup ItemIndex
// ============================================================================

	  0      "soul"         14        14     
	  1      "bless"        14        13     
	  2      "chaos"        12        15
	  3      "zen"          14        15
	  4      "life"         14        16
end
