//   Coin1   = Costo en moneda 1.
//   Coin2   = Costo en moneda 2.
//   Coin3   = Costo en moneda 3.
//   VipName = Nombre visible del boton/plan.
//
// Despues de cambiar este archivo:
//   Ejecute GetMainInfo.exe para regenerar SilentDevsMain.bin y SilentDevsText.bin,
//   luego copie esos .bin al cliente.
//
// Nota:
//   Estos valores son visuales del cliente. El GameServer aplica el beneficio real por AccountLevel
//   usando los rates AL1/AL2/AL3 de GameServerInfo - Common.dat.
