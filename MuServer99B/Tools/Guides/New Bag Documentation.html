Bag System Guide

Introduction

This document describes how to configure the bag system in the SSeMU emulator for Mu Online. It allows you to customize drop rates, included items, and their specific attributes.

Section 0: OLD BAG System Configuration

Field Description
ItemDropRate Item drop success rate, expressed as x/100.
MoneyAmount Amount of zen dropped.
ItemDropCount Maximum number of items that can drop. Use * to drop all.
SetItemDropRate Drop rate for Ancient items, expressed as x/10000.
ItemDropType (0) Fixed option values, (1) Random option values.
EffectValue (0) None, (1) Fireworks, (2) Medal sound, (3) Effect 1, (4) Effect 2.

Section 1: Items Configuration in OLD BAG

Field Description
Index Item index.
MinLevel Minimum item level.
MaxLevel Maximum item level.
Durability Item durability.
SkillOption (0) No skill, (1) With skill.
LuckOption (0) No luck, (1) With luck.
Aditional Additional option value (Jewel of Life) multiplied by 4.
Excellent Number of Excellent options.
SetOption Ancient option value.
SocketOption Number of free sockets.
Duration Item duration in seconds, (0) for permanent items.

Section 2: EX BAG System Configuration

Parameter Description
Group Item drop group identification.
GroupRate Proportional rate to select the chosen group.
ItemDropRate Success rate for item drop, x/100.
MoneyAmount Amount of zen dropped.
SetItemDropRate Success rate for dropping Ancient items, x/10000.
ItemDropCount Maximum number of items that can drop (use * to drop all items in the section).
EffectValue (0) None, (1) Fireworks, (2) Medal sound, (3) Effect 1, (4) Effect 2.
RewardType (0) Items only, (1) Reward by coins, (2) Items and coins.
Coin1 Amount of Coin1 awarded.
Coin2 Amount of Coin2 awarded.
Coin3 Amount of Coin3 awarded.
DW, DK, FE, MG, DL, SU, RF (0) Drop disabled for that class, (1) Drop enabled.

Section 3: Items Configuration in EX BAG

Parameter Description
Group Item drop group identification.
Index Item index.
Level Fixed item level.
Grade Fixed Excellent option.
Durability Item durability.
Option0 - Option6 Option index from the corresponding "ItemOptionRate.txt" section, use * if not applicable.
Duration Item duration in seconds (0 for permanent items).
